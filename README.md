# 进行中药物临床试验检索

2026-11-12 从药物临床试验登记与信息公示平台采集的「进行中」试验。页面在浏览器里检索，不需要服务器。

打开站点后，用登记号、药物名称、适应症、题目或申请人搜索。筛选可按药物类型、试验分期和试验分类缩小范围。点开一条结果，才会下载那一条所在的详情分片。

地址栏里的 `#登记号` 可以直接打开对应记录。

## 本地预览

在仓库根目录执行：

```text
python -m http.server 8765 -d docs
```

浏览器访问 `http://127.0.0.1:8765/`。不要直接双击 `index.html`，否则浏览器会拦截数据文件。

## 更新数据

把新的 `临床试验_进行中_详情.csv` 放在仓库根目录，然后执行：

```text
python build_site.py
```

脚本会重写 `docs/data/`。原始 JSONL 和整表 CSV 体积超过 GitHub 的单文件建议值，已在 `.gitignore` 里排除。
