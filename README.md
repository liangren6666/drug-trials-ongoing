# 临床试验检索

面向通用访客的药物临床试验公开数据检索页。当前快照采集于 **2026-11-12**，包含 **12,869** 条登记。

页面以 #349E75 玉绿色、暖白底和自托管 Noto 中文字体呈现。首页含三张 AI 生成的科学与自然主题轮播图，提供手动切换与暂停，并遵循减少动态效果偏好。轮播图片是概念视觉，不代表具体试验或机构。

## 查询与详情

- 关键词可检索登记号、药物、适应症和试验题目，多个关键词以空格分隔。
- 直接按药物类型、试验分期、招募状态和试验分类筛选。
- 结果支持登记时间排序、分页和 CSV 导出；点击研究名称查看详情。
- 返回研究列表会保留条件、排序和页码。地址栏 `#登记号` 支持直达详情。
- 手机端以垂直研究条目展示，不需要横向拖动表格。

本页为静态快照，当前状态请以[来源平台](https://www.chinadrugtrials.org.cn/clinicaltrials.searchlist.dhtml)公示为准。

## 本地预览

```text
python -m http.server 8767 --bind 127.0.0.1 -d docs
```

访问 http://127.0.0.1:8767/，通过 HTTP 打开以正常读取 JSON。

## 更新数据

把 `临床试验_进行中_详情.csv` 放在仓库根目录，再执行：

```text
python build_site.py
```

如果同时存在 `临床试验_进行中_整理.csv`，构建会补入招募状态和列表基本信息。缺失详情会明确提示，不会编造。

## 检查

```text
node --test tests/app.test.cjs
```

涵盖筛选、空结果、分页排序、详情请求竞争和轮播行为。
