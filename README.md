# 进行中药物临床试验检索

2026-11-12 从药物临床试验登记与信息公示平台采集的「进行中」试验。页面在浏览器里检索，不需要服务器。

页面沿用来源网站的查询布局，配色使用 `#349E75` 绿色系：绿色页头、浅绿搜索区、六列结果表格，每页 20 条。可用登记号、药物名称、适应症或题目搜索；展开「二级查询」，可按字段、药物类型、试验分期、试验分类和招募状态筛选。

支持登记号与试验状态排序、页码跳转、下载全部命中结果为 CSV，以及打印当前页。点击登记号查看详情，再按需下载对应详情分片；返回查询结果时保留查询条件、排序与页码。

地址栏里的 `#登记号` 可以直接打开对应记录。

## 本地预览

在仓库根目录执行：

```text
python -m http.server 8765 -d docs
```

浏览器访问 `http://127.0.0.1:8765/`。不要直接双击 `index.html`，否则浏览器会拦截数据文件。

## 更新数据

把新的 `临床试验_进行中_详情.csv` 放在仓库根目录，然后执行：

```text
python build_site.py
```

脚本会重写 `docs/data/`。原始 JSONL 和整表 CSV 体积超过 GitHub 的单文件建议值，已在 `.gitignore` 里排除。

如果根目录同时存在 `临床试验_进行中_整理.csv`，构建时会将其中的招募状态和列表基本信息补充到搜索索引。缺少该文件时仍可构建，招募状态留空；详情缺失的记录会提示采集不完整，不会编造详情。
